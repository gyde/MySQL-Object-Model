This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

### Running tests
Tests run inside a Docker container against a real MySQL and Memcached server. Setup is required once:

```sh
./docker/build_container
./docker/bootstrap_container /absolute/path/to/MySQL-Object-Model/
```

Then run the full test suite:
```sh
./run_tests
```

To run a single test class or method from inside the container:
```sh
sudo docker exec -it mom-unit-test sh -c "cd /srv/mom/tests && ./phpunit-9.5.28.phar --bootstrap autoload.php --configuration phpunit.xml --filter SimpleTest"
sudo docker exec -it mom-unit-test sh -c "cd /srv/mom/tests && ./phpunit-9.5.28.phar --bootstrap autoload.php --configuration phpunit.xml --filter SimpleTest::testSomeMethod"
```

### Building with a custom namespace
For projects not using Composer, copy `src/` files with a custom namespace substituted:
```sh
./build_mom my\\\\name\\\\space
# Output goes to build/ (or specify a second arg for a different output dir)
```

## Architecture

The library provides a thin active-record ORM over MySQL via PDO. All source files live in `src/` under the `Gyde\Mom` namespace (PSR-4 via Composer or `autoload.php`).

### Class hierarchy

- **`Base`** (`src/Base.php`) — Abstract base. Owns all query execution (`query`, `queryStatic`, `queryObject`, `prepare*`), caching (static PHP array + Memcached), PDO connection management, serialization, and the `describe()` mechanism that calls MySQL `DESCRIBE` to introspect table columns at runtime.
- **`Simple`** (`src/Simple.php`) — Extends `Base` for tables with a single primary key. Adds `getById()`, handles `lastInsertId()` on insert, and implements `buildSaveSql()` as INSERT/UPDATE.
- **`Compound`** (`src/Compound.php`) — Extends `Base` for tables with a composite primary key (comma-separated `COLUMN_COMPOUND_KEYS`). Adds `getByIds(array $ids)`.
- **`Exception`** (`src/Exception.php`) — Base exception. Error codes map to `MESSAGE_<code>` constants; supports i18n via `MESSAGE_<code>_<LANG>` constants and `Exception::setLanguage()`.
- **`BaseException`** (`src/BaseException.php`) — Declares all MOM error codes (1–300 range).
- **`MySQLException`** (`src/MySQLException.php`) — Wraps `PDOException`; exposes MySQL errno and message.

### Required constants on extending classes

| Constant | Required by | Purpose |
|---|---|---|
| `DB` | All | Database name (or override with `setDbName()`) |
| `TABLE` | All | Table name |
| `COLUMN_PRIMARY_KEY` | Simple | Primary key column name |
| `COLUMN_COMPOUND_KEYS` | Compound | Comma-separated key column names |

### Protected fields (auto-managed columns)

Columns with a MySQL `DEFAULT` of `CURRENT_TIMESTAMP` / `NOW()` or an `Extra` of `ON UPDATE CURRENT_TIMESTAMP` are tracked in `$__mbProtectedValueDefaults` / `$__mbProtectedValueExtras`. These fields are excluded from INSERT/UPDATE SQL **unless** the value has changed from what was loaded (`$__mbOriginalValues`). Never set these fields manually; let MySQL manage them.

### Caching layers

Two opt-in caching layers, enabled per-class via constants:

- **Static cache** (`USE_STATIC_CACHE = true`) — in-process PHP array, keyed by `<ClassName>[<selector>]`.
- **Memcached** (`USE_MEMCACHE = true`) — requires `setMemcache(\Memcached, $expiration)`. Cache keys include `CLASS_REVISION` so bumping the constant invalidates all cached objects for that class without flushing Memcached.

### Connection management

`Base::setConnection(\PDO $pdo, $global = false)` — pass `true` to set a global connection for all classes; otherwise it is scoped to the calling class. Connections are stored in `$__mbConnections` and looked up by walking the class hierarchy (`getNestedByClass`).

### Debugging

Set these constants on a model class (or on `Base` to affect all classes) to enable SQL logging. Constants accept `false` (off), `true` (write via `error_log()`), or a file path string (append to that file):
- `LOG_QUERIES` — logs every SQL statement before execution
- `LOG_QUERY_ERRORS` — logs SQL + PDO error message when a query fails
- `VERBOSE_STATIC_CACHE` — logs static cache hits/misses (true/false only)
- `VERBOSE_MEMCACHE` — logs memcache hits/misses (true/false only)

### Tests

Tests live in `tests/` and use PHPUnit 9. The `tests/classes/` directory holds concrete model stubs used by tests. The `tests/mom/` directory is a built copy of `src/` with the test namespace (generated by `build_mom` as part of the Docker bootstrap). Test classes create and drop tables in `setUpBeforeClass`/`tearDownAfterClass`, so they require a live MySQL connection.
